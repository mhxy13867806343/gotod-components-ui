GShaderMaterial3D · 空间 Shader

封装 spatial shader 的 uniform 与材质实例隔离。

Shader
shader_type spatial;
uniform float rim_power : hint_range(0.1, 8.0) = 2.5;
void fragment() { EMISSION = COLOR.rgb * pow(1.0 - dot(NORMAL, VIEW), rim_power); }

GEnvironment3D · 光照、雾与辉光

集中管理 WorldEnvironment、Sky、Fog、Glow 和色调映射。

渲染

env.glow_enabled = true
env.fog_enabled = true
$WorldEnvironment.environment = env
