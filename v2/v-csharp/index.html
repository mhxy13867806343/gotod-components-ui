GShaderMaterial3D · ShaderMaterial

从 C# 设置 shader uniform，隔离每个实例的材质状态。

Shader
var material = (ShaderMaterial)
    mesh.GetActiveMaterial(0);
material.SetShaderParameter("rim_power", 2.5f);
material.SetShaderParameter("edge_color",
    new Color(0.2f, 0.8f, 1.0f));

GEnvironment3D · 环境与后处理

配置 Sky、Glow、Fog 和 ACES 色调映射。

渲染
var environment = new Environment
{
    BackgroundMode = Environment.BGMode.Sky,
    GlowEnabled = true,
    FogEnabled = true,
    TonemapMode = Environment.ToneMapper.Aces
};
GetNode<WorldEnvironment>("WorldEnvironment")
    .Environment = environment;

C# 组件边界与 Shader 类型说明

Godot 4 C# 负责场景和资源生命周期，Shader 仍使用 Godot Shader Language。

规范
Node3D
场景树、Transform、生命周期
Resource
材质、环境、粒子资源
ShaderMaterial
SetShaderParameter
RenderingDevice
计算 Shader 高级通道
注意：C# 代码不能替代 shader 文件本身。3D 材质使用 shader_type spatial，2D 后处理使用 canvas_item，计算着色器通过 RenderingDevice 创建。
